# God's Plan · Velocity (Overdrive)

Juego web para practicar y medir la velocidad al escribir, con precisión, consistencia, curva de rendimiento y ranking global.

**Sitio:** https://velocity.godsplan.site

## Qué incluye

- Temporizador de prueba
- Estadísticas: velocidad final, precisión, consistencia
- Ranking global ("Global Elite")

## Tecnología

HTML, React (en el navegador), Tailwind CSS y Firebase.

## Probarlo en tu computadora

No necesita instalación: abre `index.html` en el navegador (usa librerías por CDN, así que requiere internet).

> **Nota de seguridad:** la configuración de Firebase que aparece en el código es pública por diseño. La protección de los datos depende de las reglas de Firestore y de la autenticación configuradas en la consola de Firebase, no de ocultar esa clave.
